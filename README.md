# Личный сайт-резюме

Резюме для стажировки: образование, занятость, проекты на GitHub и контакты.

Сайт: https://nightqwerty899-beep.github.io/resume/

## Запуск локально

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Установка зависимостей и сборка не требуются.

## Структура

- `index.html` — структура страницы.
- `profile.js` — данные резюме, проекты и контакты.
- `styles.css` — оформление, мобильная версия и стили печати.
- `app.js` — вывод данных, копирование почты и интерактивная WebGL-модель.

Для обновления данных измените `profile.js`. Каждый проект в `experience` задаётся отдельной ссылкой на GitHub. Пустые ссылки на контакты скрываются.

Сайт публикуется через GitHub Pages из корня ветки `main`.
